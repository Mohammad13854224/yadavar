# یادآور — برای توسعه‌دهنده‌ها

رابط برنامه با Svelte 5 + Vite ساخته شده و Capacitor آن را به برنامه‌ی اندروید تبدیل می‌کند. داخل برنامه، موتور واقعی انکی (کتابخانه‌ی Rust که AnkiDroid هم استفاده می‌کند) اجرا می‌شود؛ زمان‌بندی، صف مرور، نمره‌دادن و برگرداندن همه کار خود انکی است.

## ساختار

- `src/lib/engine/` لایه‌ی TypeScript که فقط از موتور انکی سؤال می‌پرسد (پوشه، کارت، صف مرور، آمار، FSRS)
- `src/lib/store.svelte.ts` وضعیت برنامه و همه‌ی عملیات
- `src/lib/brain/` نقشه‌ی سه‌بعدی مغز (three.js)
- `src/components/` صفحه‌ها: مرورها، اطلاعات، وضعیت، تنظیمات، ویرایشگر کارت، مغز
- `android/` پروژه‌ی اندروید؛ `AnkiBackendPlugin.java` پل بین رابط و موتور انکی
- `docs/` همه‌ی حالت‌های تب‌ها، همراه با شناسه‌ی تست هر کدام

## دستورها

```
npm ci
npm run check          # بررسی نوع‌ها
npm run build          # خروجی وب در dist/
npx cap sync android   # کپی آن در پروژه‌ی اندروید
```

## تست‌ها

تست‌ها موتور را با بسته‌ی رسمی پایتونی `anki` (همان کد Rust) مقایسه می‌کنند و برنامه را مثل یک گوشی، سر تا ته امتحان می‌کنند. اول محیط پایتون `../yadavar-server` را بساز (`pip install -r requirements.txt` داخل `.venv`):

```
npm run test:engine
npm run test:reviews
npm run test:info
```

## ساخت APK

هر push، در GitHub Actions تست‌ها را اجرا می‌کند و APK می‌سازد. با push کردن یک تگ نسخه (مثل `v1.0.0`)، APK در صفحه‌ی Releases هم منتشر می‌شود. کلید امضا فقط در Secrets مخزن (`SIGNING_KEY`) نگه داشته می‌شود و داخل کد نیست.
